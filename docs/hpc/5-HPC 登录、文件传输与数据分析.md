## 2. 绘图与结果查看

HPC 计算完成后，可以通过以下两种方式查看生成的图片和结果。

### 方案 A：使用 SCOW 集群虚拟机查看图片

SCOW 集群虚拟机入口：

http://10.68.247.123:81/loginCluster

操作流程：

1. 通过 SSH Terminal 登录 HPC。
2. 在 HPC 上运行数据处理、分析和绘图代码。
3. 在终端中直接修改代码并重新运行。
4. 打开 SCOW 集群虚拟机，查看生成的图片和图表。

**优点：** 不需要频繁下载图片，可以在集群环境中完成计算和可视化查看。

### 方案 B：下载图片到本地查看

1. 在 HPC 上运行代码并生成图片。
2. 使用 SFTP 节点 `10.68.247.101` 下载图片。
3. 在本地电脑打开图片，检查绘图效果。
4. 根据结果修改代码，再次运行并下载新图。

**优点：** 可以直接使用本地图片查看工具，适合需要反复检查图表的场景。

## 3. 本地 Cursor + HPC 的协作工作流

如果本地电脑内存充足，可以采用「HPC 负责计算，本地电脑负责分析」的方式。

推荐流程：

1. **HPC 计算：** 在 HPC 上运行耗时较长的计算任务，生成处理后的数据文件。
2. **SFTP 下载：** 使用 `10.68.247.101` 将生成的数据下载到本地。
3. **本地分析：** 在本地电脑打开 Cursor，对已经生成的数据进行分析、统计、绘图和结果整理。
4. **迭代优化：** 如果需要重新计算或生成新的数据，再回到 HPC 运行相应任务。

这种方式可以充分利用 HPC 的计算资源，同时发挥本地 Cursor 的代码编辑、AI Agent 和数据分析能力。

> **注意：** 如果数据量较大，应先评估本地内存和磁盘空间。对于超大数据集，建议尽量在 HPC 上完成预处理，只将必要的结果下载到本地。

## 4. 推荐工作流程总结

| 任务 | 推荐环境或节点 | 说明 |
|---|---|---|
| SSH 登录 HPC | `10.68.247.110:8022` | 终端操作、运行任务、修改代码 |
| AI Agent 辅助编程 | SSH Terminal | 在终端环境中辅助开发 |
| 上传、下载文件 | `10.68.247.101` | SFTP 传输速度较快 |
| 查看集群生成的图片 | SCOW 虚拟机 | 无需将图片下载到本地 |
| 本地代码编辑与分析 | 本地 Cursor | 适合分析已下载的数据 |
| 大规模计算与数据处理 | HPC | 利用集群计算资源 |

### 核心建议

- **HPC：** 负责计算、数据处理和生成结果。
- **SSH Terminal：** 负责远程登录、运行命令和修改代码。
- **SFTP：** 负责高效传输文件，优先使用 `10.68.247.101`。
- **SCOW 虚拟机：** 负责查看集群生成的图表。
- **本地 Cursor：** 负责对下载的数据进行进一步分析和开发。

这样可以形成一套比较顺畅的工作流：**HPC 计算 → SFTP 下载 → 本地 Cursor 分析 → 必要时返回 HPC 重新计算。**
