5.0 前提说明

FragPipe 是图形化软件（含 MSFragger 搜库、TMT 定量、DIA 流程），而集群的计算节点上没有显示器，因此需要靠 X11 转发把“软件窗口的画面”经网络传到你面前电脑上显示——软件本身仍在集群上运行，观感类似远程桌面。实现方式有二：网页桌面（5.1 方式 A，无需在本机装任何东西）或本地 X server（方式 B）。平台已部署 FragPipe 24.0 镜像：

/lustre/software/fragpipe/24.0/fragpipe-24.0-local.sif
module load singularity/ce-3.8.0

若使用中发现平台 FragPipe/DIA-NN 版本偏旧，可向平台反馈，软件更新由平台负责。

5.1 准备工作（二选一）

方式做法备注
A. SCOW Web 桌面（推荐，无需本地 X 软件）浏览器打开 http://hpc.szbl.ac.cn，用集群账号密码登录门户（网页系统名 SCOW，官方手册首页即有入口）→ “登录集群 → 桌面 → 新建桌面（登录节点）→ 连接”，得到一个网页版 Linux 桌面在网页桌面里打开终端执行 5.2 命令，FragPipe 图形窗口会直接显示在这个网页桌面中
B. 本地 X11 转发本机装 X server（Xmanager / MobaXterm），SSH 客户端开启 X11 forwarding，ssh -Y 节点 连入画图/弹窗可显示到本机（xclock 可自测）

5.2 在计算节点上启动 FragPipe（窗口版）

两种方式二选一：方式一（手动）逐条敲命令，适合想了解每一步细节的同事；方式二（推荐）用配套脚本 fragpipe_gui.sh 一键启动，并自带“空闲自动退出”——搜索完成后长时间无人操作时自动关闭 FragPipe 并释放节点，避免忘记退出一直烧核时。

方式一：手动命令（逐步执行）

# 1) 申请 32 核节点并登录（务必走这条，FragPipe 需要计算节点资源）
salloc -N 1 -n 32          # 默认 cu-1；也可 -p cu-debug -N 1 -n 32 快速测试
ssh -Y cuXXX               # 登录计算节点（-Y 开启 X11 转发，画图必需）

# 2) 进入数据目录并加载环境
cd ~/你的分析目录
module load singularity/ce-3.8.0

# 3) 启动 FragPipe GUI（弹出图形窗口即成功；整块照抄即可，--bind/--env 是容器“接线”参数，暂不必理解）
singularity exec \
  --writable-tmpfs \
  --bind $HOME/.Xauthority \
  --env XAUTHORITY=$HOME/.Xauthority \
  --env LC_ALL=C.UTF-8 \
  --env LANG=C.UTF-8 \
 /lustre/software/fragpipe/24.0/fragpipe-24.0-local.sif \
  /fragpipe_bin/fragpipe-24.0/fragpipe-24.0/bin/fragpipe
提示两种方式首次启动都一样：初始化需要较长时间（终端持续输出、界面可能 5～20 分钟才出现），不要误以为卡死而中断；看到初始化步骤完整跑完才算就绪。用 SCOW 桌面方式时，可最小化窗口等待。

方式二（推荐）：一键脚本 fragpipe_gui.sh

配套脚本 fragpipe_gui.sh 与本指南 HTML 放在同一文件夹：把它上传到集群（任意目录，例如 ~/scripts/），然后在计算节点上运行。脚本已内置方式一的全部启动命令，并自带“空闲看门狗”；FragPipe 会在你运行脚本时所在的目录工作，所以先 cd 到数据目录再运行。

# 前置同方式一：登录节点 salloc → ssh -Y 进入计算节点 → 进入数据目录
salloc -N 1 -n 32
ssh -Y cuXXX
cd ~/你的分析目录

# 一条命令：启动 FragPipe + 自动看管（默认连续 30 分钟无操作自动退出）
# 注意换成脚本实际所在路径（示例假定脚本放在 ~/scripts/）
bash ~/scripts/fragpipe_gui.sh

# 想延长空闲时间（例如 60 分钟）时：
bash ~/scripts/fragpipe_gui.sh 60

脚本帮你完成的事：

1
启动前自检：没开图形转发（缺 DISPLAY）会提醒改用 ssh -Y；确认当前节点确实属于你的 salloc 作业，防止误在登录节点运行；module load singularity 已内置，无需手动敲。
2
看门狗监测：每分钟统计你名下所有进程（含 MSFragger/DIA-NN 子进程）的 CPU 时间增量——搜索运行中绝不会误退；搜索已完成且连续 30 分钟无计算活动，才判定“无人使用”。
3
自动收尾：先关闭 FragPipe（最多等 30 秒），再 scancel 你的作业释放节点。届时 ssh 会话会断开、退回登录节点，属正常现象，不是报错。
4
想提前走：直接关闭 FragPipe 窗口（脚本立即收尾）；或在这个终端按 Ctrl+C（立即收尾退出）。
“自动退出”的判定口径为“连续无计算活动”：搜索在跑时绝不触发；触发前 5 分钟终端会打印提醒；你继续操作任务（CPU 恢复活跃）即重新计时。想整段保留更久，用更大的分钟数（如 bash fragpipe_gui.sh 120）。注意：脚本收尾会 scancel 整个作业——若该节点上还有你的其他任务在跑，请先处理或不用本脚本。

5.3 GUI 操作流程与关键配置（与本地 FragPipe 一致）

1
Workflow 模块：DIA 数据选 DIA_SpecLib_Quant；TMT 数据按标记数选 TMT10（10 标）或 TMT16（16 标及以上）。
2
添加文件：点 “Add files” 加入谱图文件（选对 Raw/文件类型）；可在左侧 “Set DDA / Set DIA” 设定数据模式、添加生物学重复。
3
Save as manifest：保存为 manifest 文件，下次分析 “Load manifest” 一键载入，无需重复设置。
4
Database 模块（FASTA 配置）：加载 fasta（可 Download 或 Browse 上传）；界面显示 decoys: 50% 属正常默认（FragPipe 自动加 decoy，无需手工混入 decoy 序列）。
5
Run 模块：设置输出位置 → 先点 Dry run 检查流程无报错 → 再点 RUN 正式运行。
6
TMT 数据额外一步：RUN 前须回到上方 workflow 输入数据处，对通道（channel）做注释（标签对应关系）。
DIA-NN 在 FragPipe 中的配置（DIA 工作流） 选择 DIA_SpecLib_Quant（DIA 搜库定量）工作流后，FragPipe 会调用内置的 DIA-NN 完成 DIA 数据的搜库与定量，界面上与之相关的参数区（workflow 展开后的 DIA-NN 模块）一般保持默认即可。三个口径要点：① FASTA——Database 模块加载的 fasta 同时供 DIA-NN 使用，建议与《DIA-NN 数据分析》分册（第 2 册）同口径：reviewed 序列、不手工混 decoy（FragPipe 自动加）、contaminant 按需；② 谱库——可指定已有谱库，或让 FragPipe 用 FASTA 生成（library-free 直搜，等同分册 2 建库逻辑）；③ 酶切与修饰——漏切数、可变修饰等参数与分册 2 命令行版 DIA-NN 语义一致（同一引擎；漏切/修饰在建库端定格，后期收紧需重新生成谱库）。具体界面选项随 FragPipe 版本略有差异，以实际界面为准；参数取舍疑问可对照分册 2 的 4.1 铁律与说明框。
其他设置想自定义/增加修饰位点：在 MSFragger 模块的红色区域选择与自定义。FragPipe 各模块更详细的原理与结果解释，参考官网 “Using FragPipe” 文档。

5.4 结果与收尾

输出目录中重点关注 dia-quant-output 文件夹（DIA 定量结果，一般直接对该文件夹内容做下游分析）。GUI 跑批会占住计算节点，界面可挂后台；正式大批量分析仍建议转成命令行/sbatch 方式执行（见分册 2），避免图形会话断线影响。

用完释放节点分析结束关闭 FragPipe 窗口后，同样要 两次 exit（退出计算节点 + 退出 salloc），或 scancel JOBID，防止一直烧核时。若用 5.2 方式二（fragpipe_gui.sh）启动，收尾已由脚本自动完成（自动 scancel），无需再手动退出。

六、课题组容器 Web 服务（FPDN_viewer 等）经验（进阶）

本章写给“要把分析工具做成网页给组里共用”的同事，属进阶内容：只做自己数据分析的新手可直接跳过，不影响前面各章。FPDN_viewer 一类图形化查看器用于把 DIA-NN/FragPipe 结果以网页形式分享查看。

课题组在集群容器环境部署过图形化查看器（如 FPDN_viewer，Shiny 应用）。此类“常驻网页服务”与普通作业不同，几点经验备忘：

1
服务需手动拉起并保持运行：在 Web 门户/容器作业页面启动容器服务，复制终端给出的访问地址（形如 http://10.68.247.45:6080/ai-forward/...）分享给组内使用。初始化界面提示“约 120 小时”等长时任务提示属正常，可放心等待或直接使用。
2
服务在后台持续运行并计费：关闭浏览器页面不会停止服务——容器服务等同作业，一直按核时/存储计费。用毕请及时 Stop/删除容器作业（平台推荐“用时拉起、不用即停”）。
3
分享链接即可访问：对方无需 HPC 账号，只要您的容器服务在运行即可打开链接使用；但一旦您 Stop 或删掉作业，所有人立即无法访问，分享前请确认使用时段。
4
别人正在用时不要随手 Stop：如组内同事正在使用该网页服务，停止操作会影响他们（先沟通再停）。
